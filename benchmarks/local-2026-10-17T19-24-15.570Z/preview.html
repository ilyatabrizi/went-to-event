Method and limits

ItemDetail
Target127.0.0.1 only. No requests sent to the live site or external services in this run.
BuildAPI TypeScript and web Vite production builds both passed before measurement.
ServerActual compiled Fastify routes with a 100-event synthetic repository injected; external services disabled.
Static deliveryBuilt HTML/JS/CSS served from memory by a minimal Node HTTP server; no CDN, compression or browser cache.
ConcurrencyVirtual users are sequential request loops, not simultaneous browser instances or logged-in accounts.
Browsing20-second stages with 1s think time, 10/100/250/500/1,000 users; not full browser journeys.
Stress15-second stages, no think time, 100/1,000/2,000 workers; stage cap 60,000 requests plus in-flight requests.
TimingFull body download included. Elapsed time includes stagger, final request drain and last think pauses.
PercentilesNearest-rank percentiles over all requests, including failed requests. Errors also reported separately.
WarmupEach route fetched once before the first stage; 1.5s rest between stages.
Fixture100 synthetic copies of existing seed events, IDs bench-0..99, future dates; no database writes.
ExclusionsDatabase latency, query scaling, auth, bookings, payments, chat, emails, writes, browser rendering and internet latency.
Resource caveatServer and load generator share one Mac. CPU, loop lag and throughput include this contention.
Observed stress behaviorThroughput peaked at 100 workers, then declined at 1,000 and 2,000. Connection resets occurred in the latter stages; root cause was not isolated.
